# Woodland micro-ambience

Eight original, reproducible synthesized mono WAVs, authored by
`scripts/art/generate_woodland_audio.py`. No sampled commercial recordings.
Three short songbird phrases, paired owl hoots, a quiet 8-second cricket loop,
wing flutter, dry-leaf movement and a twig crack. 22,050 Hz / 16-bit mono.

Playback is spatial and deliberately quiet, on the existing Ambience bus.
Maximum four one-shot voices and one local insect loop. Night cues are rare,
15–30 m away, outside the camera frustum, and never imply an actual attacking
creature. Existing weather/ground-anomaly events have priority over these cues.
Cold, rain, shelter, sleep, death and inactive player mode suppress activity.
