# Field journal art sources

Original AI-generated artwork created for Deadly Night in this development session; not copied from The Long Dark or another game. No claim that a particular external model (e.g. Nano Banana) was used: generated with the available image generation tool.

- `item_atlas.jpg`: original 5×4 painted inventory atlas. Twenty cells: brush, stone, flint, pyrite, camp kit; birch/spruce/beech/oak logs, birch firewood; spruce/beech/oak firewood, axe, lantern; compass, matches, knife, bedroll, campfire.
- `../icons/*.png`: extracted individual transparent 320×320 runtime images. Background-connected dark pixels removed; source paintings retained. Species have distinct bark art. Bedroll is an illustration for the existing sleep UI, **not a new craftable item**. Campfire is the installed-fire illustration.
- `../journal_background.jpg`: original dark textured paper, subtle forest and contour-line illustration; runtime shell background, not a full-screen postprocess.

Art direction: painterly realistic illustrated wilderness field guide; warm upper-left illumination, restrained desaturated woodland materials, clear silhouettes, no text or logos. Object atlas requested five columns and four rows, every object isolated with padding on a flat dark background. Background requested dark charcoal-green paper, worn edges, faint contour lines and conifer silhouettes confined to edges, quiet central space for controls.
