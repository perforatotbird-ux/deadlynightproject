# Health supply pictograms

`icons/{water,raw_water,ration,berries,bandage,compress}.svg` are original editable
vector drawings authored for this implementation. They contain no external image
or font dependencies, no third-party artwork and no generated branding. They are
not part of the older AI-painted PNG atlas. Source is the SVG itself.

These are technical vertical-slice supply illustrations; world pickups use small
boxes with corresponding billboard pictograms, not finished food/medical 3D art.
