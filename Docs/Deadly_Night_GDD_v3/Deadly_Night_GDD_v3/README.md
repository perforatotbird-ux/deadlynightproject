# Deadly Night — GDD v3.0

Новая версия по двум исходным документам.

- `GDD_FULL.md` — весь GDD одним файлом.
- `00_Overview.md` — главная страница и навигация.
- `01`–`07` — отдельные разделы.
- `sources/` — неизменённые исходные документы.

Формат: Markdown UTF-8; открывается в VS Code, Obsidian и других Markdown-редакторах.
Факты по дневнику, спорные места и новые предложения разделены. Код и сборка не проверялись при создании этого GDD.
