# Исправления после проверки игроком: иконки, размеры карточек, дождь

## Иконки и запуск

`run.bat` прежде сразу запускал MapViewer. Кэш `.godot` не хранится в Git,
поэтому чистый source checkout мог запускаться без готовых импортированных изображений.

- Перед запуском выполняется **синхронный инкрементальный** `--headless --editor --import`.
- Игра не запускается при ненулевом exit code либо `ERROR:` в import log.
- Лог: `%TEMP%\DeadlyNight-import.log`. Первый запуск после обновления может занять дольше.
- До импорта проверяются LFS pointers во всех PNG иконок. Если вместо картинки получен
  указатель, launcher сообщает `git lfs install && git lfs pull`, а не открывает пустой UI.
- `JournalArt` больше не кэширует `null` навсегда. Добавлен резервный декодер настоящего
  исходного PNG; LFS pointers отсекаются по PNG signature, не отправляются в image decoder.
- Карточка повторяет попытку загрузки, если её данные не изменились, но texture осталась пустой.
- Для `.bat` задан `text eol=crlf` в `.gitattributes`.

Проверка чистого импортного кэша: отдельный минимальный проект с теми же 20 PNG,
их `.import` и тем же `JournalArt`; импорт с нуля загрузил **20/20** иконок.
Сам Windows batch здесь не исполнялся — среда Linux; проверены порядок/защиты launcher
и эквивалентная команда Godot. Экспортированные PCK используют обычный ResourceLoader.

## Карточки вдвое компактнее

- Предметы: minimum **76×150 → 38×75**, сетка **4→8** колонок, на узком окне **3→6**.
- Рецепты: minimum **110×190 → 55×95**, сетка **2→4** колонок.
- Реальные высоты проверены, а не только значения `custom_minimum_size`.
- Внутренняя раскладка иконки/названия/массы перестроена под 75/95 px. Маленькая
  карточка не остаётся с прежним VBox на 150 px, переполняющим её границы.
- Текст не уменьшен вдвое: 12–13 px в карточках; длинное название сокращается,
  полностью доступно в подсказке и правом инспекторе. Кнопки действий не превращены
  в маленькие нечитабельные мишени. Глобальный scale меню не менялся.

## Дождевая «гребёнка» у земли

- Удалены плоские XZ-кольца всплесков, которые лежали близко к поверхности.
  Вместо них — маленькие camera-facing капли **над** точкой попадания,
  с плавным угасанием; нет копланарной геометрии, пересекающей terrain.
- У дождя и всплесков отключены transparent depth writes и specular highlights;
  shadow casting уже был выключен и остаётся выключенным. GI также отключён у эффектов.
- Локальные капли переиспользуются до пересечения земли, а не продолжают лететь
  ниже неё. Опорные высоты берутся из ограниченного общего terrain cache с шагом 4 м.
  Это не raycast для каждой из 900 капель.
- Во время заполнения/движения: максимум 6 запросов за 0.1 с (до 60/с короткими
  сериями), затем кэш неподвижного игрока не переснимается. Отдельные всплески
  сохраняют прежние максимум два запроса за 0.22–0.45 с.
- Кэш хранит ограниченную окрестность, старые клетки удаляются. Он учитывает только
  существующий `camp_ground`. Маска крыши сохранена, внешний дождь не выключается
  целиком при входе в дом. Gameplay намокания/укрытий не менялся.

[Контрольный кадр земли во время дождя](qa/ui_rain_hotfix/rain_ground.png).

Точный артефакт на GPU игрока без его скриншота и Forward+ здесь не воспроизведён.

Compatibility гребёнки нет. Не заявляется проверка на целевом Windows GPU.
