# Level Design Document: «Весенний лес» (MVP)

*Игра от 1-го лица в духе The Long Dark · Godot 4.7.2 · Blender + MCP · карта 4×4 км*

## 0. Как пользоваться документом

Документ в двух частях. **Часть I** — дизайн уровня: что строим и с какими числами. **Часть II** — серия промптов для ИИ-ассистента с Blender MCP: один промпт = один этап, выполняются строго по порядку. Все числа и координаты ассистент на этапе 0 сохраняет в `spec.json`, поэтому дальнейшие промпты короткие и ссылаются на него.

**Принятые допущения** (скажи, если что-то не так):

- «Воксельные деревья» понимаю как разрушаемые: ствол рубится по 3 стадиям, летят кубические щепки и опилки. В MVP стадии — заранее подготовленные меши; настоящие воксели — вторая итерация.
- Специфику Godot 4.7.2 я не могу проверить, поэтому ассистенту велено сверять API и совместимость плагинов с актуальной документацией, а не с памятью.
- Первая цель — карта в Blender и HTML5-просмотрщик (three.js). Перенос в Godot и геймплей — отдельный блок промптов G1–G5.
- Источники моделей: Poly Haven, ambientCG, Quaternius, Kenney (CC0) и Sketchfab (только CC0/CC-BY, с записью в `LICENSES.md`).

# ЧАСТЬ I. Дизайн уровня

## 1. Концепция

Игрок один в весеннем лесу среднегорья Центральной Европы (Карпаты/Альпы, апрель–май) с топором и рюкзаком. Тишина, ветер, ручей, утренний туман в долине. Маршрут MVP: старт у дороги → по дороге в сторону гор → заброшенная шахта.

Столпы уровня:

1. **Читаемость.** Скальная вершина на северо-востоке, дорога и река — ориентиры, видимые сквозь лес. Потеряться можно только намеренно.
2. **Лес как ресурс.** Любое дерево можно срубить; породы различаются временем рубки и выходом древесины.
3. **Постепенное открытие.** Поляна → дорога → ручей → предгорья → шахта.
4. **Производительность.** 60 FPS на GTX 1060 / 1080p при дальности видимости 800+ м.

## 2. Технические рамки

| Параметр | Значение |
| --- | --- |
| Размер карты | 4000 × 4000 м, начало координат в центре (±2000) |
| Единицы | 1 unit = 1 м |
| Оси Blender | X — восток, Y — север, Z — вверх. При экспорте glTF → Godot: (x, z, −y) |
| Высоты | 0–400 м; heightmap 16 бит: 0…65535 = 0…400 м |
| Heightmap | 4096 × 4096 (≈0,98 м/px), PNG 16 bit + `.r16` |
| Splatmap | 4096 × 4096, две RGBA-текстуры |
| Чанки | 16 × 16 по 250 м: единица куллинга, стриминга и расстановки |
| Превью-меш в Blender | сетка 4 м (1000 × 1000 ячеек) из 256 чанков; в игре геометрия строится из heightmap |
| Проходимый уклон | до 40° |
| Скорость игрока | ходьба 2 м/с, бег 5 м/с, присед 1 м/с |

**Бюджеты:**

- Деревья ≈ 80 000 (для первого прогона достаточно 40 000), кусты ≈ 120 000, валуны ≈ 2 000, валежник ≈ 3 000.
- Трава не расставляется по карте: генерируется процедурно только вокруг игрока (до 60 м).
- LOD деревьев: 0–60 м — полная модель (до 8k tris), 60–250 м — LOD1 (до 1,5k), 250–900 м — кроссплейны/импосторы (до 40 tris), дальше туман и отсечение. Кусты: LOD0 до 40 м, LOD1 до 120 м.
- Один MultiMesh на пару «чанк × вид растения»; LOD через `visibility_range`, а не вручную.
- Одновременно «живых» (рубимых) деревьев не более 16 (пул объектов).
- Текстуры растительности: один атлас на вид, до 2048².

## 3. Карта: зоны и ключевые точки

Все координаты ориентировочные: ассистент может сдвинуть точку до 150 м ради красоты рельефа, но обязан сохранить топологию (что с чем связано и где есть пересечения).

| ID | Название | X, Y (м) | Высота, м | Назначение |
| --- | --- | --- | --- | --- |
| SPAWN | Поляна старта | −900, −1100 | ≈25 | радиус 70 м; по кругу 5 учебных деревьев на расстоянии 20–40 м; пень и поваленный ствол |
| FORK | Развилка дороги | 600, 200 | ≈60 | налево — к шахте, прямо — выход с карты на восток |
| BRIDGE | Мост через реку | 925, 37 | ≈70 | бревенчатый, 12 м, на восточной ветке дороги |
| FORD | Брод через ручей | 795, 520 | ≈85 | на ответвлении к шахте |
| WINDFALL | Бурелом | −1500, −300 | ≈45 | завал поваленных деревьев, трудный проход |
| CLEARCUT | Старая вырубка | −1100, 900 | ≈70 | пни, подлесок, хороший обзор |
| HUT | Лесная сторожка (после MVP) | −200, 800 | ≈60 | пока только маркер |
| MEADOW | Горный луг | −1500, 1300 | ≈120 | открытая панорама |
| MINE\_YARD | Площадка шахты | 1100, 1180 | ≈140 | ровная площадка 40 × 40 м у скальной стены |
| MINE\_ADIT | Вход в штольню | 1130, 1210 | ≈143 | портал смотрит на юго-запад (азимут 225°) |
| LOOKOUT | Скальный выступ | 700, 1550 | ≈230 | обзор на всю карту |
| PEAK | Вершина «Каменная голова» | 1500, 1500 | 380 | главный ориентир |

Маршрут MVP SPAWN → MINE\_ADIT по дороге ≈ 3,2 км, около 26 минут шагом.

**Сплайны (контрольные точки X, Y):**

- **Дорога** (гравий, 4 м): (−2000,−900) → (−1400,−1000) → (−900,−930) → (−300,−600) → (200,−300) → FORK. Восточная ветка: FORK → BRIDGE → (2000,−500). Ветка к шахте: FORK → (900,700) → (1050,1000) → MINE\_YARD (пересекает ручей бродом FORD).
- **Река «Быстрая»** (5→8 м): (1550,1800) → (1500,1200) → (1300,600) → (900,0) → (500,−700) → (100,−1300) → (−100,−2000).
- **Ручей** (2–3 м): (700,1350) → (850,950) → FORD → (900,250) → (1000,150) → впадает в реку.
- **Тропы** (1 м): T1 SPAWN → дорога (−900,−930); T2 SPAWN → (−600,−1500) → (0,−1450) к реке; T3 дорога (−300,−600) → (−600,0) → CLEARCUT; T4 CLEARCUT → MEADOW; T5 дорога (200,−300) → (0,300) → HUT; T6 HUT → (300,1300) → LOOKOUT; T7 MINE\_YARD → (900,1400) → LOOKOUT; T8 дорога (−1400,−1000) → WINDFALL.

## 4. Рельеф, вода, дороги

- **Базовый рельеф:** fBm (4–5 октав, амплитуда 40 м, длина волны 300–600 м) + горный массив на северо-востоке (радиальная маска от PEAK радиусом 400–1100 м и хребет (700,1750)–(2000,1000)) + ridged-шум на склонах массива для скальных рёбер. Детали мельче 0,5 м — только normal map и detail-текстура, не геометрия.
- **Профиль высот:** долина реки 0–40 м; лесные холмы 40–120 м; предгорья 120–220 м; массив до 380 м. Уклон > 35° — скалы и осыпи.
- **Река:** глубина русла 1,2 м, берега плавные 10–20 м; вода — лента по сплайну на уровне дна +0,9 м; пойма — галька и грязь.
- **Дорога:** гравий 4 м, продольный уклон ≤ 8 %, «горбатый» профиль, кюветы 0,3 м, просека 10 м без деревьев.
- **Тропы:** 1 м, утоптанная земля, канавка 5 см, деревьев на тропе нет, лес подходит вплотную.
- **Площадка шахты:** выровненная 40 × 40 м, врезана в склон; за ней скальная стена 12–15 м с порталом.

## 5. Растительность

| Зона | Условие | Состав | Плотность, дер./га |
| --- | --- | --- | --- |
| Долина | 0–60 м | бук 30 %, дуб 20 %, берёза 30 %, ель 20 % | 90 (у реки 60) |
| Смешанный лес | 60–180 м | бук 40 %, ель 40 %, берёза 10 %, дуб 10 % | 90, в «чащах» 150 |
| Хвойный пояс | 180–300 м | ель 85 %, бук 10 %, берёза 5 % | 60 |
| Скалы и луга | > 300 м или уклон > 35° | деревьев нет: скалы, осыпи, альпийская трава, пятна снега в тенистых лощинах | 0 |

Поляны (SPAWN, CLEARCUT, MEADOW) — 0. Группировка шумом масштаба 40–80 м, минимальная дистанция между стволами 2,5 м (Poisson disk).

| Порода | Высота | Ø ствола | Весенний вид |
| --- | --- | --- | --- |
| Бук | 22–30 м | 0,5–0,9 м | гладкая серая кора, молодая светло-зелёная полупрозрачная листва |
| Дуб | 18–26 м | 0,6–1,0 м | толстый ствол, листва только распускается — крона прозрачнее |
| Берёза | 14–22 м | 0,25–0,45 м | белая кора, серёжки, светлая листва |
| Ель | 20–32 м | 0,4–0,8 м | тёмно-зелёная коническая крона |

**Кусты и подлесок:** лещина (опушки), терновник (поляны), ежевика (вырубка, овраги), можжевельник (склоны, луг), папоротник-орляк (под буком). Цветочные декали: медвежий лук в долинах, подснежники и ветреница. Валуны — 8 вариантов, валежник — стволы и ветки.

**Трава:** весной 15–35 см, ветер в шейдере, на дорогах и тропах отсутствует.

**Палитра:** молодая листва `#8DB84A`, хвоя `#2F4F2F`, прошлогодняя подстилка `#6B5232`, земля `#4A3A2A`, гравий `#8A8578`.

## 6. Деревья и рубка

Топор бьёт по дереву (дальность 2 м). Урон копится, ствол проходит 3 стадии повреждения, затем дерево падает.

| Стадия | Порог HP | Что видно | Эффекты |
| --- | --- | --- | --- |
| 0 | 100 % | целый ствол | — |
| 1 | ≤ 70 % | зарубка ≈ 20 % сечения со стороны игрока, светлая древесина | щепки и опилки, звук удара |
| 2 | ≤ 35 % | зарубка ≈ 50 % сечения, торчат щепки | больше частиц, треск |
| 3 | ≤ 10 % | зарубка ≈ 80 %, ствол наклонён на 2°, крона дрожит | скрип-предупреждение |
| Падение | 0 | дерево падает от игрока (игровая условность) | гул, удар, облако щепок |

**Прочность (HP) и выход:** берёза 8 ударов / 2 полена по 4 кг; ель 12 / 3 по 5 кг; бук 16 / 4 по 7 кг; дуб 20 / 5 по 9 кг. Урон 1 за удар, пауза между ударами 0,8 с.

**Опилки:** `GPUParticles3D`, one-shot: 24 частицы-кубика 1–3 см, жизнь 0,8 с, конус 35° вокруг нормали попадания и вверх, скорость 1,5–3 м/с, гравитация; цвет по породе (берёза и бук — светло-бежевый, ель — рыжий, дуб — коричневый). Плюс 3–5 крупных щепок по 5 см. Пул из 8 эмиттеров.

**Структура дерева:** `Tree_<порода>_<id>` = `Crown` (меш кроны) + `TrunkUpper` + `ChopZone` (нижние 2,5 м, меши стадий 0–3) + `Stump`.

- **MVP:** 4 запечённых меша ChopZone на породу, различающихся зарубкой; у среза ступенчатая «воксельная» текстура древесины.
- **v2 (настоящие воксели):** ChopZone — сетка вокселей 10 см (сечение до 10 × 10, 25 слоёв ≈ 2 500 вокселей), только для активного дерева.

**Активация:** при приближении к дереву на ≤ 25 м его инстанс в MultiMesh скрывается (scale 0), и подставляется сцена из пула; при уходе возвращается. ID срубленных деревьев хранятся в `removed_trees` (сейв).

**После падения:** ствол — `RigidBody3D` с капсульным коллайдером, через 3 с замораживается; крона исчезает через 20 с; остаются пень высотой 0,6 м, полена и 2–4 палки.

## 7. Заброшенная шахта

**Снаружи:** площадка → скальная стена → деревянный портал (две стойки и перекладина, 3,0 × 2,6 м), рельсы узкоколейки (колея 0,6 м) уходят в штольню, ржавая вагонетка, обрушенный сарай, отвал породы.

**Интерьер — отдельная сцена** `mine_interior` (переход: `Area3D` в портале, затемнение 0,5 с). Причина: коллайдер heightmap не имеет объёма, туннель «под землёй» в той же сцене работает ненадёжно.

| Элемент | Параметры |
| --- | --- |
| Главная штольня | длина 70 м, сечение 2,6 × 2,4 м, подъём 3 % вглубь, деревянные рамы каждые 3 м (≈23), рельсы по центру |
| Камера A (слева, на 30 м) | 8 × 6 м: ящики, бочки, стеллаж |
| Ветка B (справа, на 45 м) | 25 м, последние 6 м затоплены (вода 0,3 м), капель |
| Зал (конец, 70 м) | 12 × 10 × 4 м, частично обрушен; вертикальный ствол с лестницей, перекрытый завалом |
| Свет | нет; ambient 0,02; полоса света от входа; маркеры для будущих ламп и факела |
| Звук | реверберация, капель, гул ветра у входа |

Проходимость: ширина ≥ 1,2 м, потолок ≥ 2,2 м.

## 8. Игрок, управление, рюкзак (для блока G)

- **Контроллер:** `CharacterBody3D`, капсула r 0,35 м × h 1,8 м, глаза на 1,6 м (в приседе h 1,2 / глаза 1,0), ступенька 0,4 м, FOV мира 80°, FOV viewmodel 60°.
- **Управление:** WASD, мышь, Shift — бег, Ctrl — присед, Space — небольшой прыжок (0,6 м), E — взаимодействие, ЛКМ — удар топором, Tab — рюкзак, 1–4 — слоты, Esc — пауза.
- **Топор в руке:** viewmodel в правой руке, idle sway, покачивание при ходьбе; анимации: idle, замах, удар, отдача. Рисуется поверх мира и не пролезает в стены (отдельный слой/камера в `SubViewport` или shader с приоритетом глубины).
- **Рюкзак:** вместимость 25 кг, список предметов с весом (полено 4–9 кг); при перегрузе скорость 70 %. Панель по Tab: иконка, название, количество, вес.
- **Шаги** по поверхностям (по splatmap): земля, трава, листва, гравий, дерево (мост), вода.

## 9. Атмосфера

Время — раннее утро: низкое солнце с юго-востока (азимут 110°, высота 20°), тёплый ключевой свет и холодный голубой ambient. Дымка в долинах, слабый объёмный туман, дальний туман от 150 до 900 м. Каскадные тени до 150 м, SSAO вкл., SDFGI по умолчанию выкл. (включать только после замера FPS). Ветер: шейдер крон и травы, сильнее на высоте. Звук: ветер, весенние птицы, река и ручей (с затуханием по расстоянию), скрип деревьев.

## 10. Критерии приёмки MVP

**Блок 1 — карта и HTML5-просмотрщик:**

- Карта 4000 × 4000 м, heightmap 4096 PNG 16 bit; в Blender видны рельеф, река, ручей, дорога, тропы.
- Все точки из таблицы POI на месте и подписаны маркерами.
- Не менее 40 000 деревьев 4 пород и 60 000 кустов размещены по правилам зон; ноль объектов на дороге, тропах, воде и площадках.
- Шахта: портал снаружи + интерьер по спецификации.
- HTML5: открывается через локальный сервер; камера: орбита, полёт, ходьба по земле; телепорт к POI; не менее 30 FPS на ноутбуке.

**Блок 2 — Godot:**

- Персонаж ходит по карте, топор виден в руке, работают все базовые действия.
- Любое дерево в радиусе взаимодействия рубится: 3 стадии, опилки, падение, брёвна попадают в рюкзак.
- Вход в шахту без загрузки дольше 2 с; 60 FPS на GTX 1060.

# ЧАСТЬ II. Промпты для ИИ-ассистента

## Как работать

- Выполняй промпты по одному и только после проверки результата предыдущего (скриншоты, файлы, цифры в отчёте).
- «Общий префикс» ниже положи в постоянные инструкции ассистента либо вставляй перед каждым этапом.
- Если этап не удался, напиши: «Повтори этап N, учти ошибку: …». Этапы идемпотентны: они перезаписывают свои выходные файлы.

**Общий префикс:**

```
Ты — технический художник и разработчик инструментов. Работаешь в Blender через MCP и, если доступно, в файловой системе и командной строке (если нет — скажи об этом сразу).
Проект: папка forest_map. Единственный источник чисел — spec.json: читай его в начале КАЖДОГО этапа, значений не придумывай.
Правила:
1) делай только текущий этап, к следующему не переходи;
2) тяжёлую математику (шум, эрозия, Poisson disk, маски) считай через numpy в execute_blender_code или внешним Python-скриптом, а не руками по объектам;
3) не создавай десятки тысяч отдельных объектов — только инстансинг, Geometry Nodes или частицы;
4) после каждого шага проверяй результат скриншотом viewport и числами (min/max, количество);
5) в конце этапа допиши в progress.md: что сделано, выходные файлы, проблемы, что проверить человеку;
6) если сервис недоступен (интернет, Poly Haven, Sketchfab) — используй процедурный запасной вариант и честно сообщи об этом;
7) в ответе не пиши просто «готово»: покажи скриншоты и цифры.
```

## Блок A. Карта в Blender и HTML5-просмотрщик

### Этап 0. Инициализация проекта

```

1. Проверь связь с Blender MCP: версия Blender и список доступных тебе инструментов (выполнение кода, скриншот viewport, Poly Haven, Sketchfab, генерация моделей — что есть). Проверь доступ в интернет и к файловой системе, наличие numpy, Pillow, imageio (если нет — установи).
2. Создай структуру: forest_map/{spec.json, progress.md, LICENSES.md, data/, textures/, models/, blend/, export/, viewer/}.
3. Создай spec.json со ВСЕМИ числами из части I документа: размеры, оси, высоты, разрешения, чанки, бюджеты, таблицу POI, сплайны дороги/реки/ручья/троп, зоны растительности с процентами, параметры пород деревьев, параметры шахты и рубки.
4. Подготовь сцену Blender: очисти стандартные объекты, единицы — метры, clip_end 6000, вид сверху; коллекции Terrain, Water, Roads, Vegetation, Props, Mine, POI_Markers, Lighting.
5. Сохрани blend/forest_map.blend. В progress.md запиши, какие инструменты доступны и какие запасные варианты будешь использовать.
Выход: spec.json, структура папок, пустая сцена, краткий отчёт.
```

### Этап 1. Базовый рельеф

```
ЭТАП 1 — Базовый heightmap.
Сгенерируй heightmap 4096×4096 в numpy (фиксированный seed, запиши его в spec.json):
- fBm 4–5 октав: амплитуда 40 м, длина волны 300–600 м;
- горный массив на северо-востоке: радиальная маска от PEAK (r 400–1100 м, smoothstep) + хребет (700,1750)–(2000,1000); высота до 380 м; на склонах ridged-шум для скальных рёбер;
- долина вдоль будущей реки: понижение 0–40 м (используй сплайн реки из spec.json);
- лёгкое сглаживание и грубая термальная эрозия (несколько итераций).
Выход: data/heightmap_4096.png (16 bit, 0..65535 = 0..400 м), data/heightmap_4096.r16 (raw little-endian), data/heightmap_preview.png (цветной hillshade) и статистика: min/max/средняя высота, доля площади с уклоном > 35°.
```
