# Берёзы LOLIPOP — внедрение и QA

**Обновление производительности:** текущая схема дальнего леса и измерения —
[birch_forest_optimization.md](birch_forest_optimization.md). Ниже — базовая интеграция.

Дата: 2026-11-01. База: `cb010c7` (`main`).

## Результат

Вместо прежней Quaternius-берёзы используются пять форм из **Five Birch trees
pack (lowpoly, LODs)**, LOLIPOP (@lolipop_1707), CC BY 4.0. Остальные породы,
топор, руки, предметы, карта и сохранения не заменялись.

Выбор формы — `posmod(tree_id.hash(), 5)`; для пустого ID используется форма 0.
Ближний интерактивный объект, дальний MultiMesh и восстановление по сохранению
выбирают одну и ту же форму. После оптимизации дальний impostor MultiMesh
группируется по форме/исходному чанку, а авторские ближние меши — по сетке 128 м.
Индекс скрытия дерева адресует обе репрезентации, не допуская дублирования.

## Ассеты

- `art/source/lolipop/five_birch_trees_pack_lowpoly_lods.glb` — неизменённый
  пользовательский исходник; исключён из импорта редактором через `.gdignore`.
- `assets/models/external/lolipop/` — 15 разделённых GLB, 4 общие текстуры 2K,
  5 бинарных ArrayMesh `.res`, 5 лёгких `.tscn`, `manifest.json`.
- `tools/lolipop_birch/prepare.py` — воспроизводимая адаптация исходника.
- `tools/lolipop_birch/bake_lods.gd` — сборка авторских LOD в нативный ArrayMesh.
- `third_party/lolipop_birch/ATTRIBUTION.md` и игровой экран титров — атрибуция.

Высота каждой формы нормализована до прежних 18 м; исходные повороты и
выставочные смещения удалены. Геометрия, UV, нормали, исходные формы и рисунок
текстур сохранены. Текстуры уменьшены до 2048×2048 с mipmaps. LOD переключает
рендерер по экранной ошибке, не по жёстко заданному расстоянию. В массиве
вершин хранятся вершины всех трёх авторских LOD; повреждение обрабатывает только
основной индексный буфер. Точные индексы обоих дальних LOD проверены через
RenderingServer, а не только по именам/метаданным.

## Рубка и коллизии

Низ ствола в исходнике использует атлас вместе с листвой. Его связные компоненты
отделены в `Birch_bark_base`, сохранив исходную текстуру. В коллизию топора
входят кора и ствол, но не листовые карточки. Кэш коллизий теперь имеет ключ
конкретной сцены, а не только породы. Радиус обработки учитывает более широкие
разветвлённые основания; HP, число брёвен и масса не изменены.

У асимметричных оснований вырубка продолжает расширяться при повторных ударах,
вместо остановки на неизменяемой предельной ширине. Ослабление вычисляется по
действительным отдельным контурам сечения. Срез каждого ствола закрывается
отдельно, без перемычки между стволами; направление граней соответствует
clockwise front-face Godot. Текстурированная кора после деформации получает
пересчитанные касательные на worker-потоке, поэтому normal map сохраняет
корректное освещение. Тяжёлая обработка остаётся вне игрового потока.

## Проверки

Окружение: Linux, **Godot 4.7.2.stable.official.ed1daf0bf**; нативная визуальная
проверка — Compatibility, Mesa llvmpipe (программный рендерер). Независимый
импорт пяти LOD0 через Blender 5.2.3 LTS / bpy.

- `tests/test_lolipop_birch.gd`: **209 PASS / 0 FAIL** без окна;
  **212 PASS / 0 FAIL** с X11/OpenGL после HLOD, включая чтение настоящих MultiMesh-буферов.
- Проверены все пять форм, размеры, pivot, текстуры, tangent basis, alpha cutout,
  количество индексов авторских LOD, корректная группировка всех реальных
  лесных записей, скрытие/восстановление дальнего экземпляра, физический луч
  топора, повторные удары, частичный JSON-save/load, излом, два независимых
  среза у двуствольных оснований, верхние грани пней, три бревна и reload пня.
- Отдельный проект с чистым кэшем импортировал все 5 сцен и 15 текстурированных
  поверхностей без ошибок (`clean_cache.txt`).
- Девять регрессионных наборов, каждый с exit code 0: `audit_scripts`
  (73 production-скрипта), `test_external_models`, `test_tree_materials_balance`,
  `test_smooth_tree_cuts`, `test_tree_fracture`, `test_auto_chop_and_no_respawn`,
  `test_ditch_tree_fall_physics`, `test_gameplay_startup`,
  `test_main_menu_and_persistence`.
- Старые ожидания тестов актуализированы: текстурированная кора может иметь
  белый множитель albedo; открытая древесина использует отдельный материал,
  а не перекрашенную кору; путь берёзы зависит от её ID. Тест удержания ЛКМ
  теперь использует реальное время и ждёт асинхронного восстановления пня.
  Проверка глобально слабейшего высокого среза использует контролируемый
  цилиндр, чтобы не зависеть от ветвей конкретного декоративного ассета.
- Независимый Blender-import: все пять моделей прошли hard gates; нет
  нечисловых вершин, вырожденных граней, нулевых рёбер и отсутствующих
  материалов. Открытые края листовых карточек и UV-разрывы ожидаемы, это не
  печатные watertight-модели.
- Сняты и просмотрены: галерея, шесть ракурсов каждой формы, повреждения,
  изломы, пни; основная сцена MapViewer с топором, повреждением и обзором леса.

Логи, JSON-метрики и изображения: `Docs/qa/lolipop_birch/`.

## Ограничения

- **FPS на Windows / целевой видеокарте не измерен.** Нативные кадры сняты на
  программном рендерере. В world-preview уменьшены дальность/QA-видимость;
  цифры FPS в HUD этих кадров не являются бенчмарком shipping Forward+.
- Исходник статический, анимаций нет. Новая система ветра не добавлялась.
- Часть общих QA-сцен при завершении процесса печатает сообщения об оставшихся
  ресурсах. Функциональные assertions и exit codes успешны, но это не проверка
  отсутствия утечек памяти в длительной сессии.
- Результаты оптимизации и оставшиеся ограничения описаны в отдельном
  документе; аппаратный FPS нельзя выводить из скриншотов QA.

## Повторная сборка

```bash
python tools/lolipop_birch/prepare.py
Godot/godot.exe --headless --path . --editor --import
Godot/godot.exe --headless --path . --script tools/lolipop_birch/bake_lods.gd
Godot/godot.exe --headless --path . --script tests/test_lolipop_birch.gd
```

Python: NumPy и Pillow. При запуске тестов задайте отдельный пользовательский
профиль (`APPDATA` на Windows, `XDG_DATA_HOME` на Linux); сохранения игрока
удалять не нужно. Полная атрибуция и условия распространения —
`third_party/lolipop_birch/ATTRIBUTION.md`.
