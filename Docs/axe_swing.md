# Удар топором: Blender-кисти и половинная скорость

## Скорость

`AXE_ANIMATION_SPEED = 0.5` управляет одним Tween целиком. Вдвое увеличены продолжительности **всех** фаз, а не только возврата: замах, движение до контакта, проход, остановка, восстановление и интервал до следующего удара.

| Фаза | Было | Теперь |
| --- | --- | --- |
| Замах | 0,12 с | 0,24 с |
| Быстрый участок до контакта | 0,10 с | 0,20 с |
| Момент попадания от начала | 0,22 с | **0,44 с** |
| Проход после контакта | 0,055 с | 0,11 с |
| Короткая остановка | 0,025 с | 0,05 с |
| Возврат | 0,18 с | 0,36 с |
| Полный цикл с интервалом | 0,50 с | **1,00 с** |

Попадание, зарубка, опилки и звук остаются callback-ом того же Tween. Звук №1 `axe_hit_wood_01.ogg` по-прежнему воспроизводится ровно один раз. Свист замаха — отдельное событие, без дополнительного звука попадания. Пауза, инвентарь, смена инструмента, потеря фокуса и отключение контроллера отменяют незавершённый удар.

## Новая модель

- `assets/models/viewmodels/axe_grip_hands.gltf` — оригинальная модель, созданная в **Blender 5.2.3 LTS** через официальный `bpy`, не скачанная чужая модель.
- Кисть — цельная поверхность: ладонь, запястье, переходы между пальцами, четыре согнутых пальца с разной толщиной и противопоставленный большой палец. Кожаные перчатки и манжеты соответствуют выживанию в лесу.
- Прежние видимые кубы ладони, сферы суставов и цилиндры-пальцы удалены. Blender: моделирование формы, объединение объёма через voxel remesh, сглаживание и сокращение геометрии. В игре загружается готовый mesh, без Blender и без построения пальцев во время игры.
- Левая кисть запечена отдельно с исправленным порядком граней: отрицательного масштаба и пропадающих из-за него поверхностей нет.
- Правая рука держит верхнюю часть рукояти, левая — нижнюю. Кисти закреплены на рукояти, предплечья соединяются с **реальными сокетами запястий**, а не с центром топора.
- Рукава — моделированные сужающиеся поверхности с тканевыми складками. Положение локтя рассчитывается двухзвенным IK с направлением изгиба вниз/наружу. Кисти имеют фиксированную позу хвата, это не полноценный скелет с независимо анимируемыми пальцами.
- Замах дополнительно скорректирован после проверки из камеры: топор не исчезает целиком за правым краем экрана, досягаемость рук ближе к естественной.
- Формат — текстовый glTF со встроенным buffer, без отдельных текстур/бинарников и без дополнительных LFS-загрузок. Импортирует сам Godot 4.7.2.

## Исходники и воспроизведение

Полный исходник моделирования: `scripts/blender/create_axe_hand_viewmodel.py`.

```sh
blender -b --python scripts/blender/create_axe_hand_viewmodel.py -- /absolute/path/to/deadlynightproject
```

Либо `python scripts/blender/create_axe_hand_viewmodel.py` при установленном официальном `bpy==5.2.3`.

Скрипт создаёт glTF в проекте и редактируемый `.blend` с референсным топором/освещением в рабочей папке: `/data/axe-hand-work` в агентском окружении, иначе `build/axe_hands`. Шаблонные рукава/левая кисть скрыты в исходном viewport, доступны через Outliner. Python-генератор и glTF находятся в Git; редактируемый `.blend` хранится в `assets/source_blender/axe_grip_hands.blend` через Git LFS.

## Проверка

- `tests/test_axe_swing.gd`: импорт обоих mesh, отсутствие примитивных пальцев, сокеты запястий, коэффициент 0.5, отсутствие преждевременного урона, одно попадание/звук, возврат, отмена удара, эффекты.
- `tests/preview_axe_hands.gd -- --output=/path/to/previews`: реальный рендер Godot 1280×720, четыре состояния — готовность, замах, контакт, проход. Проверены изображения по отдельности. Проверка выполнена в OpenGL Compatibility; полный игровой тест/Forward+ не проводился.
- Предыдущие 96 щепок + 160 опилок не изменены.

## Интернет-референсы

- [Sylva Spoon: Anatomy of an Axe](https://www.sylvaspoon.com/blog/2020/1/16/anatomy-of-an-axe): назначение нижней/средней/верхней области рукояти и компромисс между силой и контролем.
- [Официальное руководство Blender: glTF 2.0](https://docs.blender.org/manual/en/latest/addons/scene_gltf2.html): экспорт mesh/материалов для игровых движков, в том числе Godot.
- [BlendSwap: Hands Rigged, SparrowHawk, CC0](https://blendswap.com/blend/22269): просмотр описания доступных референсов анатомических кистей. Модель не скачивалась и в проект не включалась.

Сторонние mesh и текстуры в новую модель не включены. Топор для подгонки хвата — существующий ассет проекта.
