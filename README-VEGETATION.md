# Deadly Night — vegetation update (архивная инструкция)

> **Статус (сверено 1 ноября 2026): исторический документ.** Это инструкция по распаковке архива с исходниками растительности поверх рабочей копии на базе `e00ab655`. Растительность уже влита в `main` коммитом `1d91bf6 feat(vegetation): berries, mushrooms, tea brewing and field guide tab`, поэтому распаковывать архив не нужно. Актуальное описание механики — `Docs/vegetation_implementation.md`.

Это архив изменённых и новых исходников, НЕ отдельная игра и НЕ Windows-сборка.
База: perforatotbird-ux/deadlynightproject, main, e00ab655879a482be8138d5df604ea2f9009116c.

1. Сделайте резервную копию проекта и пользовательских сохранений.
2. Распакуйте архив поверх корня соответствующей рабочей копии проекта. Не заменяйте папку целиком.
3. Откройте project.godot в Godot 4.7.2 и дождитесь импорта ресурсов.
4. Запускайте обычную сцену игры; сбор растений — E, знания — вкладка «Растения», готовка — у горящего костра.

Полный отчёт, параметры, ограничения и команды тестов: `Docs/vegetation_implementation.md`.
Список файлов: `Docs/vegetation_changes.txt`. Кадры и логи: `Docs/qa/vegetation/`.

Ручной трёхдневный survival-проход и целевая Windows/GPU-проверка по-прежнему остаются задачами приёмки.
